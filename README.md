# Bison Army Content Repository

This repository serves as the official content source for Bison Army.

## About Bison Army

Bison Army is a subscription fitness platform designed to help people build discipline through consistent fitness habits.

The platform combines:

- 15-minute workouts
- Calisthenics training
- Optional gym programs
- Workout streak tracking
- Military-style rank progression
- Community challenges (Tours of Duty)

## Content Mission

Our mission is to create research-backed, actionable content that helps people:

- Build discipline
- Improve consistency
- Develop healthy habits
- Stay committed to fitness goals
- Build long-term accountability
